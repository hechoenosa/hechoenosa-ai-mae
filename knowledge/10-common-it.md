# Common help desk problems

The everyday problems an IT help desk sees most with first-time setups. Check these before anything else.

## "This app isn't compatible with this version of macOS" (old Mac)
- Current VS Code needs roughly macOS 12 (Monterey) or newer. Check: Apple logo → About This Mac.
- macOS 11 (Big Sur) or older: don't hunt for old versions. Use the browser path. Builders on an old Mac can still do everything for Week 1 in the browser.

## Installing asks for a password
- Mac and Windows ask for the computer's admin password to install apps. That's the computer's password, not GitHub's.
- If the builder doesn't know it, a parent types it. Never share it in the chat.
- School or work computers often block installs completely: use the browser path.

## Windows: "Windows protected your PC"
- This blue screen sometimes appears for new downloads. Only if the file came from code.visualstudio.com, git-scm.com or desktop.github.com: click "More info" → "Run anyway". Anything else: stop and ask a parent.

## Windows: installer opened from inside the zip
- Some downloads are zipped. Right-click the zip → "Extract All" first, then open the installer from the new folder.

## Antivirus blocks the installer
- Close it, download again from the official site only, and try once more. Still blocked: a parent can allow it, or use the browser path.

## Can't find what I downloaded
- Look in the Downloads folder. In the browser, the download arrow (top right) lists recent downloads; click the file to open it.

## Mac: the app is still in Downloads
- Drag Visual Studio Code into Applications first, then open it from Applications. Otherwise it may ask again every time.

## Not enough space
- About 500 MB needed for VS Code, more for the Mac developer tools. Empty the Trash or Recycle Bin and delete big old downloads, with a parent's OK.

## Slow or broken internet
- Big downloads (Mac developer tools) can fail on weak wifi. Move closer to the router, or try at a time when fewer people use the internet. Restart the download if it stops.

## GitHub email code not arriving
- Check spam and promotions, wait 2 minutes, click "Resend". Make sure the email is spelled right.

## GitHub asks for a "device verification" code
- When signing in on a new computer, GitHub may email a code. Same fix as above.

## GitHub asks to set up two-factor authentication (2FA)
- GitHub asks people who contribute code to add a second sign-in step. It shows a banner with a deadline. A parent should help: use an authenticator app on a parent's phone, and save the recovery codes somewhere safe (printed or written down). Never send recovery codes to anyone, including AI-Mae.
- Official guide: https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa

## Forgot the GitHub password
- github.com/login → "Forgot password?" → reset link by email. The reset email goes to the email they signed up with (a parent's for under-13s).

## The browser didn't come back to VS Code after "Authorize"
- Pop-up or "Open Visual Studio Code?" box was missed. Click Authorize again and choose "Open". Still stuck: close the browser tab and try the step again from VS Code.

## Typing gives wrong characters (quotes, backtick, @)
- The keyboard language may be set to a different layout. Spanish keyboards put symbols in other places. Typing quotes by hand fixes "smart quotes" copied from Notes or Word.
- Caps Lock on? Passwords and commands care about capitals.

## Everything is frozen
- Wait one minute. Then close the app (Mac: Cmd + Q, or Apple logo → Force Quit; Windows: Ctrl + Shift + Esc → Task Manager → End task). Then restart the computer.
