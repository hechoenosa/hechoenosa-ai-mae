# General help: computer skills for the hackathon

Small skills builders need for every week. Teach one at a time, with the keys for their computer.

## Take a screenshot
- Mac: Cmd + Shift + 4, then drag a box around the part you want. It lands on the Desktop. Cmd + Shift + 5 shows more options.
- Windows: Windows key + Shift + S, then drag a box. It's copied; paste it with Ctrl + V, or click the pop-up to save it.
- Chromebook: Ctrl + Shift + Show windows key (the box with two lines), then drag.
- Phone: usually power + volume up (iPhone) or power + volume down (Android).
- Only the error or the window. Crop out faces, names, emails and passwords.

## Copy and paste
- Mac: select, Cmd + C to copy, Cmd + V to paste. Windows and Chromebook: Ctrl + C, Ctrl + V.
- In the VS Code terminal on Windows, right-click also pastes.
- Copying a command from the assignment: use the copy button on the grey code box on GitHub, then paste into the terminal and press Enter.

## Search
- Find a word on a web page or in a file: Cmd + F (Mac) / Ctrl + F (Windows).
- VS Code, find a file by name: Cmd + P / Ctrl + P.
- VS Code, find a word in every file of the project: Cmd + Shift + F / Ctrl + Shift + F.
- VS Code, find any command: Cmd + Shift + P / Ctrl + Shift + P (the Command Palette).

## What the terminal is
A window where you type instructions for the computer instead of clicking. Each line you type is a command; press Enter to run it. In this program you use it for git commands like git --version and git push.
- Open it in VS Code: Terminal → New Terminal, or Ctrl + ` (backtick). It appears at the bottom.
- The terminal works inside the folder you opened in VS Code.
- Nothing printed after a command often means it worked.
- Red text or "error" means something to fix: copy the exact words or take a screenshot and ask.
- Stop a command that's stuck: Ctrl + C.
- Up arrow brings back the last command.
