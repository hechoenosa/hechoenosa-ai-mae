# The browser path

For builders whose computer can't install VS Code or Git, who are on a Chromebook, tablet or shared computer, or who keep getting stuck on Steps 4–6. Everything happens on github.com. Real developers work this way too.

## What counts for Week 1 on the browser path
- Steps 1, 2 and 3 as normal (they're already in the browser).
- Skip Steps 4, 5 and 6 for now.
- Step 13: post "I'm in" on the Wall. In the tools box, write "Browser path".

## Make and edit files in the browser (replaces Steps 8–10 and 12)
1. Do Step 7 as normal to get your own copy of hello-osa.
2. Open your repo, github.com/your-handle/hello-osa.
3. Press the . key (just a full stop) on your keyboard. A VS Code window opens right in the browser (github.dev). Same layout as VS Code, no install.
4. Click index.html and change the three ✏️ lines.
5. To save to GitHub: click the Source Control icon on the left (three dots joined by lines), type a message like "My first commit", click Commit & Push.
6. New file: hover the file list → New File icon → my-idea.md.
7. Step 11 (Go live) works the same.
Note: github.dev has no terminal, so the git commands from the assignment don't work there. The Commit & Push button does the same job.

## Coming back later
If a laptop becomes available later, Steps 4–6 take about 30 minutes, ideally with an adult next to them.
