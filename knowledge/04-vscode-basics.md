# VS Code and files, the basics

Use this when a builder is lost in VS Code or doesn't understand files and folders. Teach one idea at a time.

## Files and folders
- Your computer keeps everything in folders, like a cupboard with drawers. A folder can hold files and other folders.
- A file has a name and an ending that says what kind it is: .md is text with headings (Markdown), .html is a web page, .pdf is a document, .png or .jpg is a picture.
- The path is the address of a file, from the top drawer down. Example: Documents → hecho-en-osa → hello-osa → index.html. Mac writes it Documents/hecho-en-osa/hello-osa/index.html; Windows writes it with \ instead of /.
- Mac: open folders in Finder. Windows: open folders in File Explorer.
- To see where a file lives from VS Code: right-click it → Reveal in Finder (Mac) / Reveal in File Explorer (Windows).

## What VS Code is
A place to write code and text files. It's like a notebook that understands code. It doesn't make the files by itself: you create them.

## Where things are in VS Code
- Left side, Explorer (two pages icon): the files and folders of the project you opened.
- Middle: the file you're editing. Each open file is a tab at the top. A white dot on a tab = not saved yet.
- Bottom, Terminal: where you type commands like git --version. Open it with Terminal → New Terminal.
- Left side, Source Control (three dots joined by lines): shows changed files, and lets you commit.
- Command Palette: Cmd+Shift+P (Mac) / Ctrl+Shift+P (Windows). Type what you want to do.
- Save: Cmd+S / Ctrl+S. Undo: Cmd+Z / Ctrl+Z.

## Open a folder
File → Open Folder → pick the folder → Open. VS Code now shows everything inside it on the left. Most "I can't find my file" problems are a different folder being open.

## New file or folder
Hover over the folder name in Explorer → New File icon (page with +) or New Folder icon (folder with +) → type the name with its ending → Enter.

## Your project folder (where the program is heading)
You'll have one folder named after your project. Inside it, over the weeks:
- my-idea.md — your idea (Week 1)
- PRD.md — what your product does and for whom (Week 4)
- TRD.md — how you'll build it (Week 4)
- your presentation file (Week 7)
Plus the code AI helps you write from Week 5.
