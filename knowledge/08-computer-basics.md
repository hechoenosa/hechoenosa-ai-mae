# Computer basics from zero

Many builders and parents are new to computers. Never assume they know a word. If they seem lost, explain the word in one short sentence, then show where it is on their screen. One idea at a time.

## Words people might not know
- **Browser:** the app you use to open websites. Chrome, Safari, Edge and Firefox are browsers. GitHub opens in a browser.
- **Address bar:** the long box at the very top of the browser where a website address goes (like github.com). Typing an address there goes straight to the site. Typing in the Google search box only searches for it.
- **Tab:** each website open in the browser has a tab along the top. Click a tab to switch. The small x closes it.
- **App / program:** something you install and open, like VS Code. Mac: in the Applications folder and the Dock (row of icons at the bottom). Windows: in the Start menu (four squares, bottom left).
- **Window:** the box an app or folder opens in. You can have many windows open.
- **File:** one thing saved on the computer: a picture, a document, a web page. Its name ends with a dot and a few letters, like my-idea.md or photo.jpg.
- **Folder:** a container for files and other folders, like a drawer.
- **Download:** copying a file from a website onto your computer. It goes to the Downloads folder.
- **Installer:** a file that puts a new app on your computer. You open it once, follow the steps, and then you can delete it.
- **Zip file (.zip):** a packed file. Double-click it and it unpacks. On Mac, VS Code downloads as a zip.
- **Terminal:** a window where you type commands instead of clicking (see General help).
- **Account / sign in:** your name and password for a website. GitHub is an account.
- **Username / handle:** your name on GitHub. Not your real name.
- **Repository (repo):** a project folder that lives on GitHub.

## Where things live on the computer
- **Mac:** open **Finder** (the blue smiling-face icon in the Dock). On the left: Desktop, Documents, Downloads, Applications.
- **Windows:** open **File Explorer** (the yellow folder icon at the bottom, or Windows key + E). On the left: Desktop, Documents, Downloads.
- **Downloads:** everything you download lands here first.
- **Documents:** where to keep your project. The program uses Documents → hecho-en-osa.
- **Desktop:** the background screen. Screenshots on Mac land here.
- **Make a new folder:** Mac Finder: File → New Folder. Windows File Explorer: right-click an empty spot → New → Folder. Type the name, press Enter.
- **Hidden endings:** Windows often hides the ending (.md, .html). If a file seems to have no ending, that's why. In File Explorer: View → Show → File name extensions.
- **System files:** folders like Windows, Program Files, System or Library belong to the computer. Never move, rename or delete anything there. Your work goes in Documents.

## Keyboard and mouse
- **Enter** (sometimes called Return or Intro): runs a command or confirms.
- **Cmd** (⌘) is on Mac. **Ctrl** is on Windows. Shortcuts use Cmd on Mac where Windows uses Ctrl.
- **Shift:** the key with an up arrow, used for capital letters and some symbols.
- **Backtick ( ` ):** usually top-left, under Esc. On Spanish keyboards it may be next to the P key.
- **Right-click:** Mac trackpad: click with two fingers, or hold Control and click. Windows: the right mouse button, or two-finger tap on the touchpad.
- **Double-click:** click twice quickly to open something.
- **Drag:** click, hold, move, let go.

## Opening, closing, restarting
- **Close an app completely:** Mac: Cmd + Q (the red dot only closes the window). Windows: the X in the top-right corner of the window.
- **Restart the computer:** Mac: Apple logo → Restart. Windows: Start → Power → Restart. Save your files first.
- **Find any app or file:** Mac: Cmd + Space, type the name. Windows: press the Windows key, type the name.

## Safety basics
- Only download from the official sites named in the assignment (code.visualstudio.com, git-scm.com, github.com).
- Never share your password or the code GitHub emails you. Not with friends, not with AI-Mae.
- If a website asks to install something extra or shows lots of ads, close it and ask a parent.
